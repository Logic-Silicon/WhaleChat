## 一句话

**多气泡只给「跟角色聊天」；Ask 的问答回复回到原来那张卡。**

## 这一版改了什么

2.382 的多气泡写在共用页面里，结果 **Ask 的回复也被拆成了小气泡、名字被移到卡外**。
这一版补上判据：

- 只有**角色会话**才按行拆气泡（短句小药丸、长句自动换行、文字上下间距对称）；
- **Ask 恢复 2.35 的原样**：一张卡 + 卡内「DeepSeek」标签 + 换行显示，不拆气泡；
- 用户消息、错误消息、时间戳、复制 / 重新生成等行为都没变。

> 红线复核：Ask 的 system prompt、请求、会话数据、设置页一个字没动。
> 这次改的只是「Ask 回复长什么样」—— 因为这个页面是共用的，2.382 被牵连了。

## 其它（与 2.382 相同）

- 三份皮肤：基础款 / 魔丸 / 贴吧老哥；
- 老用户升级首次点鱼先给「保留原来的大肥鱼 / 换个性格」；
- 版本号按 +0.001 递进。

## 升级注意

- 只装 release 包；`-debug.apk` 与 release 签名不同，装它要先卸载，**那才会清空记录**；
- `adb install -r` 覆盖安装保留数据。

## 已知限制

- 「贴吧老哥」仍保留原卡脏话风格；
- 多气泡只按换行拆，整段不换行的回答仍是一个气泡。
