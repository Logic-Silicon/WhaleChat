# 累积公告：从 2.0 到 2.383（对外唯一一次公开更新）

> **适用场景**：上一次公开更新是 **2.0**，之后 2.001 → 2.383 全是内部迭代；
> **2.383 是 2.0 之后对外公开的版本**。所以这份文案要从 2.0 讲起，
> 而不是从 2.3 或 2.33 讲起 —— 用户手里只有 2.0，中间那些版本号对他没有意义。
>
> 渠道：GitHub Release / 酷安 / 群公告 / 官网。
> 若要单个 GitHub Release 正文，用 `v2.383.md`；那份是「这一版改了什么」，
> 这份是「从你手上那版到现在，一共变了什么」。

## 正文

> **WhaleChat** 是跑在 Wear OS 上的非官方 DeepSeek 客户端，纯手表端独立运行，
> 手机上什么都不用装。你手上的 2.0 之后，我们没有再对外发过版本 ——
> 这半年攒下来的东西，全部集中在 **2.383** 里。下面是它和 2.0 的差别。

### ① 三星手表打字看不见字 —— 换了整条路（2.001）

2.0 时我们承认过这个 bug 修不了。后来换了思路：**不再用应用自己的输入框**，
改用 Google 为 Wear 推荐的系统全屏输入界面。输入由系统接管，三星 / Gboard / 第三方
走同一条路 —— 这类「某家输入法的怪毛病」从原理上不存在了。

代价也说清楚：输入不再内联，确认后回到 App 里点发送；改 API Key 这类要整段重输。

> 2.33 起还多做了一件事：**进入输入页不再自动弹输入法**，改成点一下输入卡才拉起。
> 原来自动拉起正好撞上页面转场，实机上大概率黑屏。（三星键盘**自身首次唤出**仍可能黑，
> 那是键盘 App 自己的问题，应用侧修不了。）

### ② 长按任意消息，能改、能删、能重来（2.1 / 2.2）

- 你发的消息：**编辑重发 / 复制文本 / 删除此信息**
- 她的回答：**重新生成 / 复制文本**
- **任意一条提问都能改**了（2.0 只准改最新那一问）。代价是它后面已生成的内容会作废，
  所以点下去会先告诉你具体会删掉几条，确认了才动。

菜单本身也重做过两轮，现在是 M3E 官方形态，2 项 3 项都不用滚。

### ③ 说话像人了，不像客服（2.3）

输出规矩整份换成 8 条「像在聊天软件上打字」：一次一到三条、每条一行、
**允许只回一个「嗯」或「?」**、不每轮抖机灵、不复述上一轮、不用「还有什么可以帮你的」收尾。

### ④ 公式和 Markdown 能看了（2.31）

化学式、数学式不再是一堆反斜杠：`\mathrm{S}^{2-} + 4H_2O \rightarrow` 会显示成
`S²⁻ + 4H₂O →`。**只改显示**，消息原文、复制出来的内容、发给模型的上下文都不变。

### ⑤ 她知道现在几点、你们多久没聊（2.32）

每次发送会带一行本地算出来的「此刻」：现在几点、你们上次聊是多久前、她正在干嘛。
半夜三点她也会困，不会永远在线。这一行不联网、不进聊天记录。

### ⑥ 大肥鱼有三副性格（2.34，2.38 / 2.381 调整）

基础款 / 魔丸 / 贴吧老哥。第一次点她先挑一个；
想换只需长按「重新开始 → 换个性格」，聊天记录会清空，但角色不用重造。

> 原「小女儿」皮肤已在 2.38 **删除**；原「MC老登」皮肤已在 2.381 **删除**。

### ⑦ 隔得久了，她会先开口（2.35）

距你上次说话超过 4 小时再点开会话，她会先发 1–3 句：按皮肤分语气、按当前时段关心你。
**纯本地拼句子，不联网、不调模型、零成本**。设置里能关。

### ⑧ 她说两三句，就是两三个气泡（2.36 首版，2.382 修好，2.383 起只给角色会话）

一条回复按行拆成多个气泡，短句就是一个小药丸、长句自动换行。
2.36 首版有两个毛病：首泡多一行名字导致高低差、短句被 Card 的最小高度撑成大空泡；
**2.382 重做渲染**——名字移到气泡组上方、气泡按内容收缩、上下内边距按实测补偿到对称
（`top=6dp / bottom=8dp`，复测上下都是 10.8dp）。只改显示，复制 / 重新生成仍是整条。
**Ask（一次性问答）不拆**：仍然是一张卡 + 「DeepSeek」标签，和以前一样。

### ⑨ 她开始记得你的事（2.37）

每聊 6 轮，后台整理一次「关于你、值得长期记住的事」—— 称呼、口味、正在准备的考试、
明确说过的边界。之后聊天她会真的提起来。

- 记忆存本机（`files/memories.json`），**删角色就连记忆一起删**；
- 每个角色最多 10 条、全局最多 40 条；不建向量库、不加权限；
- 「重新开始」**不清记忆** —— 清的是聊天记录，不是这个人。

### 还是那些原则

- 只连 **DeepSeek 官方 API**；没有统计、没有遥测、没有后台推送；
- Key 与聊天记录只存手表本机，已关闭系统云备份；
- 人设与输出规矩是可复盘的固定文本，不是每次现编；
- 语音识别默认走设备自带，只有你主动切到讯飞/通用接口时录音才会外发。

### 升级注意（从 2.0 升上来必看）

1. **第一次点大肥鱼**：已经和她聊过天的老用户会先看到一页「大肥鱼更新了」——
   可以直接选「保留原来的大肥鱼」（人设、开场白、聊天记录都不动），
   也可以选一个新性格；全新安装的用户直接挑一个。
   **无论选哪个，聊天记录都不会被删。**
2. **「小女儿」「MC老登」皮肤已下架**：之前选过它们的设备，启动时一次性换回基础款；
   聊天记录还在，通讯录里那条鱼也还在，名字会变回「大肥鱼」。
3. **主动消息默认开启**：设置 →「角色聊天 → 她会主动开口」可以关。
4. **长期记忆默认开启**：删角色会连记忆一起删；不想留可以只删角色重造。
5. 档案格式与 2.0 兼容，**不需要重装清数据**。
6. 覆盖安装请用**同一签名**的包：release 装 release；把 debug 包装到 release 设备上，
   Android 会要求先卸载 —— 那才会清空聊天记录。

## 配图（建议 5 张，按顺序）

1. 首页（Ask）—— 证明它跑在手表上；
