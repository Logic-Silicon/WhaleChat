> 渠道选版与合规建议（GitHub / 酷安 / 应用商店分别发哪一版）是**内部决策稿**，
> 放在仓库外的本地文件里，不随仓库上传。

## 发 Release 的步骤（复盘用）

```powershell
# 1) 确认包与版本号
aapt2 dump badging dist\WhaleChat-2.383-release.apk | Select-String '^package:'

# 2) 附件只放 release，不要放 debug
gh release create v2.383 dist\WhaleChat-2.383-release.apk `
  --title "WhaleChat 2.383 — 多气泡只管角色会话" `
  --notes-file docs\releases\v2.383.md
```

⚠️ 仓库里**不要提交** `dist/`、`keystore.properties`、`keystore/`、`local.properties`、任何 APK
（`.gitignore` 已覆盖；发 Release 用附件，不进仓库历史）。
