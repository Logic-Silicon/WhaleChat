## 这一版改了什么

2.381 曾因观感问题把多气泡整段回退。这一版重做渲染（规则不变：消息仍是一条，只在显示时按行拆）：

- **名字移到气泡组上方**，不再塞进第一颗气泡 —— 首泡不再比后面的高；
- **短句按内容收缩**成小药丸，不再被 `Card` 的最小高度撑成大空泡；
- **上下内边距刻意不对称**：在 480×480 / 340dpi 模拟器上逐像素量测，
  同字号文字墨迹到气泡上沿 11.8dp、下沿 10.4dp（字体 ascent > descent）；
  改成 `top=6dp / bottom=8dp` 后复测 **上 10.8dp / 下 10.8dp**（误差 ≤0.5dp）；
- 段间距 6dp，长句在可用宽度自动换行，代码块整条不拆；长按复制仍是**整条**。

## 其它（与 2.381 相同）
