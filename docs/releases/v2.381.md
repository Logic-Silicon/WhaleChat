## 这一版改了什么

### ① 删除「MC老登」皮肤

「MC老登」（MC 技术宅）整份删除，剩下三份。选过他的设备启动时一次性换回基础款，
聊天记录不动。

### ② 回退「多气泡」

2.36 把一条回复按行拆成多个气泡，实测：
* 开场白和部分回复被拆开后，**字体在各自气泡里的上下间距不一致**；
* 短句变成两个大空泡，看起来像两条独立消息。
⇒ 回到**一条消息一个气泡**（换行仍在气泡内），观感与 2.35 一致。

### ③ 老用户升级先给选择

已经和大肥鱼聊过、且从没选过皮肤的设备：启动时人设**原样保留**，第一次点她先看到
「大肥鱼更新了」——可以直接「保留原来的大肥鱼」（人设、开场白、聊天记录都不动），
也可以「换个性格」。选定后不再出现。

### ④ 版本号改回 +0.001

从这一版起按 `2.381 → 2.382 → …` 递进；`2.39` 未外发，作废。

## 升级注意

- 只装 **release** 包。把 `-debug.apk` 装到 release 设备上会因签名不同要求卸载，**那才会清空记录**；
- `adb install -r` 覆盖安装保留数据；
- 之前选过 MC 的，升级后她会变回基础款，聊天记录还在。

## 已知限制

- 「贴吧老哥」仍保留原卡脏话风格；
- 记忆每 6 条用户消息才整理一次，刚说的事可能要再聊几轮。
