## 一句话

**大肥鱼不再是同一条鱼了：现在有五种性格，第一次点她先挑一个。**

## 这一版有什么

| 皮肤 | 一句话 |
|---|---|
| 基础款 · 大肥鱼 | 毒舌串子，爱吃白米饭；爱反串、嘴硬心软 |
| 魔丸 | 更毒的那条，夸人也像在挑刺 |
| 贴吧老哥 | 祖安选手，开口带脏字（原卡风格保留） |
| 另有两份 | 已下架，不列出（见顶部说明） |

- **首启选择页**：装完第一次点大肥鱼，先出现「挑一条鱼」——五张卡写着名字、
  一句话定位、以及那句开场白。点一张就生效，不二次确认。
- **「重新开始」可以再换**：长按 →「重新开始」→「换个性格，重新开始」；
  选中后清空记录、用新皮肤的开场白重新开始（返回则什么都不做）。
- 五个皮肤**共用一个角色**：聊天记录、通讯录排序都不动，换的只是人设与名字。
- 设计沿用原来的 M3E 语言：`ScreenScaffold` + `ScalingLazyColumn`、`surfaceContainer`
  卡片、当前皮肤带一颗「当前」药丸。

## 升级注意

- **2.33 升上来第一次点大肥鱼，会先让你挑一次**（这是有意的：不挑的话你永远只会看到基础款）。
  聊天记录不会丢 —— 换的是人设，不是历史。
- 皮肤随时能再换：长按「重新开始」即可。
- 用户自己创建的角色不受影响。

## 已知限制

- 示例对话里的说话人标签仍写作「大肥鱼」（源人设稿如此），换到其他皮肤时
  模型会不会偶尔自称「大肥鱼」还没跑够样本；遇到就当段子看。
- **部分皮肤内容风格强烈**（脏话、成人向调侃），公开渠道的合规风险
  由使用者自行判断；不喜欢随时换回基础款。
